# MiFi Dashboard

Expo + TypeScript app that controls a Huawei MiFi over local Wi-Fi via its HiLink HTTP API. No backend — the phone talks to the device at `http://192.168.8.1` directly.

## Run

```bash
bun install
bunx expo start
```

Dev build required
